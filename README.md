# Binance Scanner — App Information

This is the homepage for a personal-use data pipeline ("Binance Scanner") that
pulls Binance USD-M Futures market data and syncs it to a private Google
Sheets workspace for personal trading analysis.

This app is for personal use only, operated by a single user (the repository
owner), and is not distributed publicly.

See [privacy-policy.md](./privacy-policy.md) for the privacy policy.
